# Todd4diy｜個人實驗室

網站：https://todd4diy.github.io/

一個持續累積計畫、研究與筆記的個人空間。這裡是各項工作的**入口**，不要求所有專案都在同一個網站裡完成。

## 內容方向

| 區域 | 目前定位 | 進度 |
| --- | --- | --- |
| 算算紫微 | 紫微斗數互動服務；此處先提供專案介紹，正式產品未來獨立開發 | 規劃與開發中 |
| 虎機職訓所 | SLOT 遊戲設計的既有文章、研究與後續新內容 | 待盤點、搬遷 |
| 實驗筆記 | 學習筆記、觀察、靈感與願望清單 | 待建立內容方式 |
| 專業履歷 | 需要較完整的專業作品與資料整合，將來獨立處理 | 暫不優先 |

## 網站原則

- **簡單先上線**：先做能使用、能繼續擴充的版本，不為了未來功能提前搭建複雜框架。
- **首頁是入口**：不在首頁堆疊完整文章或服務功能。
- **中文為主**：避免中英文重複敘述，少用多餘的副標與小字。
- **真實狀態**：尚未完成的內容可以介紹，但不要提供指向不存在頁面的連結。
- **公開專案**：不要將密碼、金鑰、私密資料或個資放入 Repository。

## 技術與版本

- 發布：GitHub Pages，`main` 分支。
- 技術：靜態 HTML、CSS；有需求再加 JavaScript。
- 本機工具：Visual Studio Code、GitHub Desktop、瀏覽器。
- 網站首頁基準：**v0.2**（鼠尾草綠配色，已完成視覺檢視）。

現有主要檔案：


`js/main.js` 是早期互動測試留下的檔案；首頁 v0.2 目前不需要載入它。

## 開發與發布流程

1. 決定本次**一件小任務**。
2. AI 說明要修改哪個檔案、為何修改，並提供程式碼。
3. 在 Windows 本機修改，瀏覽器先測試。
4. 使用 GitHub Desktop：**Commit to main → Push origin**。
5. 等 GitHub Pages 部署完畢後，檢查公開網站。
6. 工作結束時，只更新 `NEXT.md` 中真正有變動的進度；有重要方向變更才寫入 `DECISIONS.md`。

## 工作交接
